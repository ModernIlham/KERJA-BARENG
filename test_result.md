# Testing Protocol
1.  **Kanban Board**:
    - Check if the page loads without errors.
    - Verify 'Assignee' dropdown is populated.
    - Test Drag and Drop functionality.
    - Test Task Creation, Edit and Delete.
    - Test 'Link Asset' search.
2.  **Asset Search**:
    - Verify search results for "Barang Keluar" are not limited to 50.
3.  **Dashboard UI**:
    - Verify text does not overflow on small screens.
4.  **Sidebar**:
    - Verify active link logic.
    - Test Collapsible functionality.
